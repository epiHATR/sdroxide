## What's new

- SatNOGS transmitter fetch for satellite freqs (override → SatNOGS → builtin); last good dump kept on failed refresh
- SAT popup layout: stable undocked size, MODE clear of the scrollbar, left-aligned link names
- Filter edges: hold `[` / `]` + arrows; SAT list arrows only when the panel has focus
- Meshtastic mode with region picker, NODES / MESSAGES / MAP panel, and LongFast decode via lorarx
- Watching tab, dock persistence, and leaner README with the full manual on the wiki

**Meshtastic / `lorarx`:** unlike the radiosonde `*mod` helpers (which ship beside
`sdroxide`), `lorarx` from dxlAPRS is **not** bundled in the install package. Install
it on the machine that runs the radio (OpenWebRX+ package `dxlaprs-lora`, or a
binary from [oe5dxl.hamspirit.at](http://oe5dxl.hamspirit.at:8025/aprs/c/)) so it is
on `PATH`, then restart sdroxide. Without it, MESH mode shows the missing-helper
warning and will not decode.
